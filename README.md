# ozon-vyvoz

Набор скриптов для работы с вывозом и утилизацией неликвида с FBO-склада Ozon.

Со склада Ozon периодически нужно забирать/утилизировать залежавшийся товар, иначе растёт плата за хранение. Эти скрипты тянут остатки и планы вывоза через Seller API, считают сроки и стоимость хранения и собирают готовые листы и отчёты (XLSX/CSV), по которым оформляется заявка.

## Что внутри

- `process_stock.py`, `turnover_by_stock.py` — остатки по складам и оборачиваемость
- `util_acts_pull.py`, `util_returns_probe.py`, `util_analyze*.py` — выгрузка и разбор актов вывоза/утилизации
- `build_report.py`, `detail.py`, `make_util.py`, `add_prices.py` — формирование отчётов и листов вывоза с ценами
- `compare.py`, `check_wh.py`, `analyze_plan.py` — сверка списка со складом и анализ плана
- `cdp.py`, `chrome_debug.bat` — добор данных из личного кабинета через Chrome DevTools Protocol (там, где нет API)

## Настройка

Доступы к Ozon Seller API берутся из переменных окружения (см. `.env.example`):

```
OZON_CLIENT_ID=...
OZON_API_KEY=...
```

Запуск любого скрипта: `python -X utf8 <script>.py`.

Заявку на вывоз Ozon создаёт вручную в кабинете — публичного API для создания заявки нет, поэтому скрипты только готовят данные и листы.
